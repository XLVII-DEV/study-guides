<h1>Transaccions i Propietats ACID</h1>
<p>Una transacció agrupa diverses operacions SQL perquè s'executin com una unitat indivisible: o es confirmen totes amb <code>COMMIT</code> o es desfan totes amb <code>ROLLBACK</code>.</p>
<div class="summary-strip">
  <div class="pill-box"><span class="pill-label">Regla d'or</span><strong>Tot o res (Atomicitat)</strong></div>
  <div class="pill-box"><span class="pill-label">Confirmació</span><code>COMMIT</code> fa els canvis permanents</div>
  <div class="pill-box"><span class="pill-label"> Recuperació</span><code>ROLLBACK</code> torna a l'estat previ</div>
</div>

UPDATE comptes SET saldo = saldo - 100 WHERE id = 1;
UPDATE comptes SET saldo = saldo + 100 WHERE id = 2;
COMMIT;</code></pre>
  <div class="callout trap"><strong>Trampa d'examen:</strong> deixar una transacció oberta sense <code>COMMIT</code> ni <code>ROLLBACK</code> manté els bloquejos actius i congela altres sessions.</div>
  <details class="oral-check">
    <summary>Pregunta d'entrevista: què passa si cau el corrent just després del COMMIT?</summary>
    <div class="oral-ans">Gràcies a la <strong>Durabilitat (D)</strong> i al registre <em>Write-Ahead Log (WAL)</em>, en arrencar de nou el SGBD reconstrueix i conserva el canvi confirmat.</div>
